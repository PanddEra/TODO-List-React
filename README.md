# React Todo List

#### Simple Todo application built with React and Bootstrap.

## Live View
https://todo-list-react-panddera.netlify.app/

## Features
* Add tasks
* Mark tasks as completed
* Delete / toggle tasks (click item)
* Form validation

## Tech Stack
* React
* Bootstrap 5

## Run Project
1. Clone or download repo
2. Install dependencies
```bash
npm install
```
3. Start dev server
```bash
npm run dev
```
